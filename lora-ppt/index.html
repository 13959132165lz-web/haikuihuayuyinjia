ComfyUI 三大工作流

comfyUI-局部重绘制

模型：Qwen Image 2.1 Turbo

蒙版局部修图工作流

在原图上圈出要处理的区域，适合修手指、补鞋尖、删除多余手臂、移除头饰，或补画道具挡住的衣料。

  1. 载入原图
  2. 圈选编辑区
  3. 扣除脸和头发保护区
  4. 裁出局部及周边
  5. 移除或重绘
  6. 按蒙版贴回原图
  7. 检查并保存

模型只接收选区附近的裁切图，周边保留少量上下文，让新画的轮廓、颜色和笔触能接回原稿。贴回时以原图为底，只写入蒙版内的像素。比如删除多余手臂，选区要从手臂接入肩部或袖口的位置一直盖到指尖，并包含需要补回的衣料。修手指时，选区要容得下整个手掌、拇指和四指，出图后再放大检查数量和关节。补脚如果需要越过原图边缘，就先扩画布，再沿现有鞋身补出鞋尖和鞋底。

ComfyUI 三大工作流

comfyUI-角色拆件

模型：Qwen Image 2.1 Turbo

角色拆件四视图工作流

从一张完整角色立绘出发，分别拆出无发头部、独立发块、无头上半身、下半身。每个部件输出正面、左侧面、右侧面和背面，合计 16 张独立的纯白底 PNG。

  1. 载入立绘
  2. 裁出部件参考
  3. 生成正面
  4. 以正面为参考生成左右侧面和背面
  5. 纯白底合成
  6. 单图保存

先用 Qwen Image 2.1 Turbo 确定各部件的正面，再让其余三面参考同一张正面，减少转面时的五官、发束、服装和配件漂移。头发单独生成，中心用连续发束填实，并检查有无封闭白洞。上半身保留垂在手下的白布，下半身保留侧腰织物和记事册。侧面、背面及被遮挡的结构来自模型推演，仍需对照原画检查。

换角色时，替换输入图、调整裁切框，再修改部件提示词里的五官、服装和不对称细节。确认基础图后，可用附带的 Lanczos 工作流等比放大像素。

ComfyUI 三大工作流

comfyUI-人物改动作

模型：Qwen Image 2.1 Turbo

  • 角色原图全身参考 + 五官裁剪
  • 动作参考裁边 + 等比适配
  • 提示词共享外观 + 单张动作
  1. Qwen 多图编码
  2. 采样
  3. 解码
  4. 纯白底合成
  5. 保存 PNG
输入在工作流里的作用
动作参考图提供躯干方向、肢体弯曲、前后遮挡和头部朝向。先裁掉截图黑边，再等比适配画布。
角色全身原图提供身材比例、发型、服装结构、材质、配色和绘画笔触。
原图五官特写给模型更清楚的眼形、瞳色、鼻唇和脸型参考，帮助维持新角度下的角色辨识度。

Lora 训练核心方法论

Lora-Gustav Klimt Vienna Secession painting

如何训练一个Lora？

  1. 关键在于素材库

    高清图片素材，需要先进行修复和甄别，保证素材风格上的一致性，避免素材本身有磨损，变形扭曲，其中面部和手部是重点修复对象，让素材保证在原始纯净的状态。

  2. 核心风格的搭建在于触发词

    触发词是Lora的概念灵魂。需要做到的是抽离触发词和打标提示词，明确以用定打（用模型生成想要的素材时我会怎么使用这个Lora模型）。

比如目前我要训练的画风是克里姆特黄金时期画风，那我要的抽象画风概念部分是 金箔表面、几何与花卉纹样，以及细腻的人物皮肤和平面装饰之间的对比。

而我要改变的部分包括五官发型，服装细节，具体背景。那我要打标的部分即 五官发型，服装细节，具体背景。
