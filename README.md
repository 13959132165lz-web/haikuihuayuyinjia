## 首页与工作流

首页使用用户提供的 red.png 原图。履历中的联系方式已移除，新增 MBTI / ENTJ；包含教育背景、五项能力、工作经历以及《古相思曲》《超能映射》《水之森林》的项目经历全文。

首页下滑到底部后沿用纵向翻页效果进入工作流。返回首页时保留阅读位置，不自动循环跳走；向上滚动可取消待执行的底部翻页。保留“个人履历”“返回首页顶部”和“继续 · 制作工作流”按钮。

玻璃项目文件夹固定在视口右下角，在首页和工作流页可用，离开第2页时随整页一起上移，转场结束后隐藏。悬停、点击或键盘可展开三个项目便签，分别进入第3、7、13页。项目入口从中央向两侧揭开页面，内容由下向上进入。展开文件夹还会显示用户提供的红.glb三维花饰，缓慢自转并上下浮动；收起、隐藏或切到后台后暂停。

工作流使用用户新提供的首页/6.png背景，满屏覆盖且不压暗。指定的首页履历文字与工作流文字加粗并使用红色液态金属效果，其余正文保留原色。“项目经历”标题也使用红色金属；MBTI、ENTJ使用13px普通正文。长文金属字形按容器宽度换行，工作流显式分行随移动端布局调整。

金属文字共用一个WebGL上下文，只有当前页视口内可见的文字参与绘制，帧率上限25fps；弹窗打开、切至后台或文字不可见时停止绘制。系统减少动态效果时显示静态帧；WebGL不可用时保留可读的金属渐变文字。

## 作品交互

人物主页面包含总览和陆鸢、沈不言、倚华、陆时四个横向子页。场景主页面包含总览和宫廷、权谋、秘境、战场、现代五个横向子页，26张场景图及1张补充图均已纳入。人物、场景和影调页用Lenis驱动横向连续滚动，桌面纵向滚轮映射为水平推进，停止后对齐完整子页；子页按钮、键盘左右键和触屏横滑保留，手机纵向手势仍用于阅读长文。服装横向图集保留独立操作。在人物、场景和影调的最后一张，继续向前滚动、向左滑动或按右箭头会沿用纵向转场进入下一页；到达最后一张时不立即跳过，滚轮惯性与移动端纵向阅读不会误触下一页。

第10页44张色调图片支持悬停、键盘聚焦和点击翻转；第11页五组影调共用右对齐的8px中英文副标题。

第12页视频顺序为原素材1、5、3、4、2，以及 showcase.mp4。第13页按超能力文件夹1—6的顺序展示视频，两页共用滚轮逐层叠放、触屏滑动、序号跳转和原生播放控件。全站共23段视频。

第14页八个人物文件夹采用统一白色玻璃质感，收录18张原始照片；点击展开后直接放大照片，不显示人物小传弹窗。第15页以左侧标题与右侧九宫格结构展示9张场景原图。第13页与第15页共用P17背景，第14页使用P16背景。

所有背景使用cover居中裁切，覆盖21:9、16:9和竖屏视口。人物、场景子页和五组影调的背景使用独立全屏图层，不受内容画布缩放影响。第3—6页主标题支持光标附近的虚线字形轮廓和节点效果。
