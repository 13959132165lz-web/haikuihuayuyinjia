# 梁臻 · AI美术作品集

十六页交互作品集。GitHub Pages 从 main 分支根目录发布，无需构建。

包含高清图片、23 段视频、液态图片交互、墨水文字和纵向翻页动效。

《古相思曲》包含视频、故事概览、角色设计、场景概念、五组影调与44张色调总览。
人物主页面包含总览和陆鸢、沈不言、倚华、陆时四个横向子页；场景主页面包含总览和宫廷、权谋、秘境、战场、现代五个横向子页。26张场景图及1张补充图均已纳入。
色调总览支持悬停、键盘聚焦和点击翻转；触屏可点击查看彩色图。

第13页为《古相思曲》视频与分镜，共六条，顺序为原素材1、5、3、4、2，以及showcase.mp4（原独立展示页视频）。独立视频展示页已移除。第14页为《超能映射》（《星域奇旅》PV），按超能力文件夹1—6的原顺序展示六条视频，并完整展示项目定位、情绪锚点与Slogan。两页共用叠放布局，支持滚轮逐层叠放、触屏滑动、序号跳转和原生播放控件。Lenis 1.3.27 分别绑定各页内部滚动容器，不影响其他页面，源码及MIT许可证保存在 assets/vendor/。参考：https://lenis.dev/ 、https://github.com/darkroomengineering/lenis 。

第14页与第16页共用P17背景，并使用“案例三 · 超能映射 / Case 3: Super Mapping”液态金属标题；副标题仅保留中英文90秒英雄命题。第13页章节标题为“视频与分镜”。第15页标题为“角色设定 / Character Setup”，按文案顺序展示8个统一白色玻璃质感人物文件夹，收录18张原始照片；点击展开后可直接放大照片，不显示人物小传弹窗。第16页采用第6页的左侧标题与右侧九宫格结构，完整展示9张场景原图。第15页使用P16背景。移动端使用两列文件夹与单列场景。

第14—16页标题使用本地液态金属WebGL着色器；仅当前页初始化和运行，帧率限制为30fps，离开页面、打开预览弹窗或切到后台时暂停，减少动态效果设置下保持静态，WebGL不可用时显示银色渐变文字。着色器和形状预处理改编自 [React Bits Metallic Paint](https://reactbits.dev/animations/metallic-paint)，许可证见 assets/vendor/REACT-BITS-LICENSE.md。文件夹交互参考 [React Bits Folder](https://reactbits.dev/components/folder)，玻璃材质参考用户提供的 [Glass Folder Cards](https://cdn.21st.dev/kedhareswer/glass-folder-cards/default/bundle.1791785999938-44a040f8-6f3a-44cb-96a2-dbb978781ac2.html)，通过原生HTML/CSS实现，不依赖外部运行脚本。

所有背景图片使用cover按比例放大并居中裁切，禁止平铺。人物、场景横向子页和五组色调的背景由独立全屏图层承载，覆盖21:9、16:9和竖屏窗口，不受1600×900内容画布缩放与裁切影响；子页、服装与影调切换会同步更新背景。

第4—7页主标题支持光标附近的虚线字形轮廓、矢量边界和节点标记，灵感来自 [React Bits Tech Text](https://reactbits.dev/text-animations/tech-text)，键盘聚焦也可查看效果。第12页五组色调共用右对齐的8px中英文副标题（原24px的三分之一）。首页右下角新增磨砂玻璃项目文件夹，悬停、点击或键盘展开后，三张项目便签以云朵式漂浮弹出；对应跳转第4、8、14页。入口翻页从中央向两侧揭开，内容从下方平移进入；减少动态效果设置下直接切换。文件夹互动参考 [Folder Float](https://reactbits.dev/c/micro/folder-float)，转场参考 [Lenis](https://lenis.dev/)。
